# Experiment 2 – Descriptive Statistics and Data Visualization

## Aim
To apply descriptive statistical measures and data visualization techniques to summarize, analyze, and interpret the distribution and relationships present in the Pima Indians Diabetes Dataset.

## Dataset
`diabetes.csv`

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset structure, dimensions, column names, and data types
- Descriptive statistical measures
- Mean
- Median
- Variance
- Standard Deviation
- Dataset summary and inspection
