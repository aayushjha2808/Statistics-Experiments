# Experiment 9 – Model Evaluation and Explainability

## Aim
To apply model evaluation, Bayesian concepts, and explainable AI techniques to interpret and understand machine learning predictions on the Pima Indians Diabetes Dataset.

## Dataset
`diabetes.csv`

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SHAP
- LIME

## Analysis Performed
- Data loading and preprocessing
- Train-test split
- Logistic Regression
- 5-Fold Stratified Cross-Validation
- Accuracy and F1-Score evaluation
- Classification Report
- Confusion Matrix
- Brier Score
- Calibration Curve
- SHAP Explainability
- SHAP Feature Importance
- Individual Prediction Explanation using SHAP
- LIME Explainability
- Final Model Evaluation and Interpretation
