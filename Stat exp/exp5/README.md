# Experiment 5 – Bootstrap and Permutation Methods

## Dataset
`diabetes.csv`

## Libraries Used
- Pandas
- NumPy
- Matplotlib

## Analysis Performed
- Dataset loading and inspection
- Selection of Glucose variable
- Bootstrap sampling
- Bootstrap distribution of mean Glucose
- 95% Bootstrap Confidence Interval
- Comparison of diabetic and non-diabetic groups
- Difference in mean Glucose
- Permutation sampling
- Permutation distribution of difference in group means
- Permutation p-value
- Hypothesis testing using significance level (α = 0.05)
- Bootstrap and permutation distribution visualizations
